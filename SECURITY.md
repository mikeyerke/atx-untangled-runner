# Security Policy

## Report a vulnerability

Please use GitHub's private **Security → Report a vulnerability** flow for this repository. Do not open a public issue containing exploit details, resident information, credentials, tokens, receipts, or screenshots.

Include the affected commit or image digest, reproduction steps, impact, and a minimal proof of concept that contains no real resident data.

## Secrets and personal data

Never submit resident data, API keys, takeover tokens, account numbers, addresses, or agency receipts to this repository. Test only with synthetic fixtures.

## Supported version

Only the image digest currently pinned by ATX Untangled production is supported. Mutable tags are informational and must not be used for production attestation.
